# Class IX English Interactive Reader

**Live:** Will be available after enabling GitHub Pages

## Features
- **Tap any sentence** → Bengali meaning appears + Voice plays that sentence
- **Play All** → continuous voice reading
- **Show All Bengali** toggle
- Full texts of:
  - The North Ship (Philip Larkin)
  - The Price of Bananas (Mulk Raj Anand)
  - A Shipwrecked Sailor (Daniel Defoe)
  - Hunting Snake (Judith Wright)
- Word Nest with English + Bengali meanings
- Critical Analysis for every lesson
- Dark / Light theme
- Installable PWA

## Enable GitHub Pages
