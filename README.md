# Class IX English Interactive Reader (Enhanced)

**Live:** https://pbwsantu-collab.github.io/A-Shipwrecked-Sailor-Hunting-Snake-The-North-ShipThe-Price-of-Bananas-/

A teaching-focused interactive reader for **WBBSE Class IX English** covering:

- The North Ship (Philip Larkin)
- The Price of Bananas (Mulk Raj Anand)
- A Shipwrecked Sailor (Daniel Defoe)
- Hunting Snake (Judith Wright)

## Features

### Reading
- Tap any sentence → Bengali meaning + voice
- Play All continuous reading with auto-scroll
- Speed control, Show/Hide all Bengali
- Mark sentences as studied (progress bar)
- Important words highlighted in text

### Vocabulary
- Word Nest with English + Bengali meanings
- Tap any word to hear pronunciation
- Flashcard mode (flip for meaning)

### Analysis
- Summary of each text
- Theme explanation
- Critical analysis

### Practice (Teaching)
- **MCQ** – multiple choice questions with instant feedback
- **True / False** statements
- **Fill in the blanks** with answer checking
- Score tracking saved locally

### Other
- Dark / Light theme
- Font size controls (A− / A+)
- Reading progress + quiz scores in footer
- Installable PWA
- Offline support via service worker
- Indian flag 🇮🇳 (WBBSE / West Bengal)

## How to use in class
1. Open the lesson tab.
2. Students read + listen sentence by sentence.
3. Mark studied lines.
4. Switch to **Practice** for quick tests.
5. Use **Flashcards** for vocabulary revision.
6. Review **Analysis** before exams.
